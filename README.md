# 🎵 Music Artist Hub

Music Artist Hub is a simple practice website I created to improve my skills in **HTML, CSS, and JavaScript**.

The project allows users to explore different South African music genres, choose an artist, and view songs associated with that artist.

> ⚠️ This project is for **practice and learning purposes only**. It is not intended to be a commercial music streaming platform.

---

## 📌 Project Description

The Music Artist Hub was created as a beginner web-development project.

The main idea is to create a simple platform where users can:

- Explore music genres
- Choose an artist
- View songs by an artist
- Play audio files added to the project
- Create an account
- Log in
- Navigate between different pages
- Log out of the music section

The project focuses mainly on practicing **front-end web development**.

---

## 🎯 Purpose of the Project

The purpose of this project is to practice and understand:

## 🖥️ Pages

The project contains several pages:

### Home Page

`welcomePage.html`

The home page introduces the Music Artist Hub and provides navigation to other parts of the website.

### Registration Page

`create.html`

Users can enter information such as:

- First name
- Last name
- Phone number
- Email
- Date of birth
- Gender
- Username
- Password

### Login Page

`login.html`

Users can enter their username and password to access the music page.

### Music Page

`music.html`

Users can:

1. Select a genre
2. Select an artist
3. Select a song
4. Play an available audio file

---

## 🛠️ Technologies Used

The project was created using:

- **HTML5** – Used to create the structure of the website.
- **CSS3** – Used to style the website.
- **JavaScript** – Used to add functionality and interaction.
- **LocalStorage** – Used for the practice login system.
- **HTML Audio** – Used to play audio files.
